This repository documents my progress while learning C++ through a sequence of small lessons and console programs. I am building the fundamentals step by step, practicing each new concept with hands-on examples.

## What I am learning

- Writing and running a basic C++ program, and working with console input and output
- Variables, data types, strings, and swapping values
- Arithmetic operations and simple geometry calculations
- Conditional logic with `if` and `else`, including odd/even checks and grade evaluation
- Loops for repeated input, sums, and generating the Fibonacci sequence
- Functions and parameters, including calculator operations and a highest common factor example
- Arrays, searching, calculations, and two-dimensional arrays

## Course projects

The numbered folders follow the course progression. Along the way, the exercises grow from introductory programs into small interactive applications, including calculators, a student grade checker, summation programs, a Fibonacci generator, and array exercises.

## Repository layout

Each lesson folder contains one or more standalone `.cpp` source files. The examples are intended to be explored and compiled individually as I continue learning; this repository is a record of practice, not a single combined application.

## Build and run

With a C++ compiler such as `g++`, compile a source file from its lesson folder:

```sh
g++ "path/to/source.cpp" -o program
```

Then run the resulting executable. For example, from the repository root:

```sh
./"path/to/program.exe"
```
